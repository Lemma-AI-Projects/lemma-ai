# Lemma AI — Agent 反馈信号·外部参考（M2）

> 日期：2026-08-08 · 调研计划：`planning/lemma-ai-agent-evaluation-research.md`
> 聚焦问题：**如何可靠地从自由对话判定教学结果（success/failed/partial），而不是靠用户点按钮 / LLM 自评打星**

## 1. Reflexion（NeurIPS 2023）——语言即强化信号

**核心**：Actor → Evaluator → Self-Reflection → 反思文本存记忆 → 下一轮读取。学习发生在**文本记忆**里，不在权重里——零微调、任何 LLM 可用。

**对我们的直接启示**：
- 评估器三选一：单元测试 / 标准答案比对 / **启发式规则或另一个 LLM**——我们属于第三种（对话里没有标准答案）
- 反思必须**回灌到下一轮输入**才有用（写了一段教训没喂回去=没写）——对应我们的 L4 episodes 要能被读回 prompt
- **护栏清单（关键）**：cap 试错次数、cap 记忆大小、**guard reflection quality**（教训必须具体可执行）、**verify evaluator 可信度**（弱评估者毒化一切反思）、watch cost——这些正是我们 M3 要带上的工程约束

## 2. Voyager（Caltech/NVIDIA）——技能库 + 课程 + 自验证

**核心**：三层架构 = 自动课程（难度自适应，好奇心驱动）+ 技能库（外部记忆，可组合复用，缓解灾难性遗忘）+ 迭代提示（环境反馈 / 执行错误 / **自验证**）。

**对我们的直接启示**：
- **自验证 = 角色分离**：主模型是"执行者"，另起一个 LLM 实例当"质检员"（不只是 yes/no，失败时给 critique）——**比主模型自我感觉可靠得多**。这直接回答了"LLM 自评行不行"：行，但必须是**独立质检角色**，不是让老师自己给自己打分
- 技能库 = "能跑的"记忆（不是"能读的"摘要）——我们的 L5 meta_rules 定位同理：规则要能影响行为，不只是存着
- 自动课程 → 对应我们未来"老师决定下一步讲什么"的方向（期望学习速率最大化，愿景 F 系列）

## 3. arXiv 2606.20138（高中辅导 LLM 教学）——**从对话提取信号的实证权重** ⭐

这是最直接可用的：用 **14 个 LLM 提取特征 × 人类专家标注的相关性**（N=138）给出权重：

**学生侧（理解度信号）**：
| 特征 | 与"教得好"的相关系数 |
|---|---|
| Justifies mistakes（解释自己的错误） | **0.436** |
| Answers mostly correct（大部分答对） | **0.387** |
| Answer ≥ 2 questions（答了 2 题以上） | **0.368** |
| Interacts > 3 times（互动 3 轮以上） | **0.315** |
| Correct within 2 turns（2 轮内答对） | **0.215** |
| Shows understanding（表现出理解） | 0.150 |
| Asks ≥ 2 on-topic questions（问 2 个切题问题） | -0.016 |
| Shows curiosity（表现出好奇） | -0.161 |

**教师侧（教学策略信号）**：
| 特征 | 相关系数 |
|---|---|
| Provides scaffolding（支架式引导） | **0.341** |
| Adapts to level（适配学生水平） | **0.295** |
| Diagnoses misunderstanding（诊断误解） | **0.248** |
| Balances explanation/questioning | 0.207 |

**一致性工程答案**：LLM 评估器做 **3 次独立运行 + 多数投票**，一致性 91.29% → 94.31%（最弱项从 82% → 90%）。

> 这给了我们 M3 的直接原料：**判 result 不用"整段对话一个分数"，而是提取这 14 个二元特征加权合成**——既诚实（锚定人类专家判断）又可工程化（3 票多数决）。

## 4. 实时自适应 AI 老师（Sahin 博客）——微行为信号

认知引擎 + 情感引擎，文本先行：
- **Hesitation**：回答前停顿时长 → 不确定
- **Correction**：输入→删除→重输 → 不自信
- **Session Breaks**：频繁短暂停 → 受挫/超载
- 触发时换模态 / 给提示 / 回退基础概念——"不是流程图，是舞蹈"

**对我们的启示**：微行为信号可作 **P2 伴随指标**（重问/停顿/删除），但需要前端埋点，优先级低于 P0 的对话内容提取。

## 5. Abel Tutor（多模态理解检测）——方向确认，太重

视频+语音实时检测 AU 动力学/TOI/声学 → 检测理解阶段。确认"理解是可检测的阶段性状态"，但多模态投入过重——**文本先行**是正确路径，我们不做视频情感识别。

## 6. LingoAce Tutor Luna（AI-native 学习引擎）

五环节循环：能力状态识别 → 动态任务生成 → 即时互动反馈 → 持续能力建模 → 学习策略优化。与我们的 L2/L4/L5 + 期望学习速率愿景**高度同构**——验证了我们的架构方向正确。

## 7. 教育反馈回路行业数据

- 实时形成性反馈：掌握率 +23%（ISTE 2025）
- NLP 评估识别误解：87% 准确率（接近人类导师）
- 实时教学反馈：教师重教时间 -34%（McKinsey 2024）

## 综合结论（M2 收官）

**"从自由对话判 result"的可靠做法，外部已经给了三重答案**：
1. **多特征合成**（arXiv）：提取学生侧理解信号（答对率/2 轮内答对/表现出理解）+ 教师侧策略信号，加权合成——锚定人类专家判断，不是拍脑袋
2. **独立质检角色 + 多数投票**（Voyager + arXiv）：执行者与质检员分离；3 票多数决把一致性推到 94%+
3. **引擎自带防自欺闸门**（我们的 learner 已内置）：partial = 无测试不动 mastery；只有 tested 才动——**判定错了也能被后续 episode 修正，不会累积污染**

再加上我们的硬约束：**显式反馈（👍/👎）作为 P1 补充**（用户主动表达通道，可选可关），行为信号（P2）作伴随指标。

## 借鉴 / 否决清单

| 做法 | 借鉴/否决 | 理由 |
|---|---|---|
| Reflexion 反思回灌 | ✅ 借鉴 | 对应 L4 episodes → 注入 prompt（C1 读路径） |
| Voyager 角色分离自验证 | ✅ 借鉴 | 独立 evaluator，不是老师自评 |
| arXiv 14 特征加权 + 3 票多数决 | ✅ **核心借鉴** | M3 判 result 的直接方法 |
| 微行为信号（停顿/删除） | ⏸️ P2 伴随 | 需前端埋点，先不做 |
| Abel 多模态视频理解 | ❌ 否决 | 投入过重，文本先行 |
| LLM 自评打星当主信号 | ❌ 否决 | 截图本质问题；必须独立质检角色 |
