## 立场（读之前先认这一条）

1. **代码是唯一事实来源。** 这里写的和代码冲突时，**以代码为准**，并回来改文档。
2. 每份文档开头都标了 **分支 / 日期 / 状态**：
   - **事实** = 在标注的分支上核对过，带 `文件:行号`
   - **约定** = 我们定下要遵守的规则（可能还没实现）
   - **未定** = 明确还不知道，别当结论用
3. 换分支看之前，先看文档标的**分支** —— 同一组件在不同分支上完成度不一样。
