## 0 · 原型要证明的一件事

不是"这个页面能用"，是**这套信息架构可以被评价**。

具体到一次评审：评审者能在 **90 秒**内走完一条路径，并且说得出三件事 ——
他看到了什么、为什么信或不信、下一步会点哪里。

说不出这三句，说明原型还没做完，不是"设计还需要打磨"。

## 1 · 范围内 / 范围外

| 范围内（本轮就做这些） | 范围外（不在这一轮） |
|---|---|
| 四个视角的信息架构与交互 | 组织真人做用户测试 |
| 视觉：材质、字号、图形尺寸 | 引擎怎么持续产出"发现" |
| 12 条核心交互 + 键盘与焦点 | 接真表、上生产、多用户 |
| 边界状态：空 / 超长 / 密集 / 矛盾 | 真实数据导入 |
| 评审包：截图、可复现链接、说明 | 移动端 |

范围外的那些不是不重要，是**不该由原型来回答**。原型回答"能不能懂"，回答不了"会不会用"。

## 2 · 五个阶段

| 阶段 | 做什么 | 做完的判据（可观察） |
|---|---|---|
| **P0 底座** | 三层材质（纸 / 板 / 浮层）、字体栈与字号、图形尺寸拉到能读 | 眯眼看截图能分出三层；时间轴的轴与节点不用盯就看见；27px 标题在两种机器上都不像宋体 |
| **P1 四个视角** | 每个视角补齐它自己那一件事，并写出一条 90 秒演示路径（§3） | 四条路径都能一次走完不断，中途不需要解释 |
| **P2 交互完整** | 12 条交互 + ↑↓/Enter/Esc + `focus-visible`；删掉所有"只在视觉上存在"的按钮 | 点遍全页，没有一个按钮点了没反应；键盘能走完一条路径 |
| **P3 边界** | 空态、超长文本、单日 30 条的密集段、互相矛盾的证据、没有任何证据的行 | 五个边界各截一张图，每张都能说出"这里说明了什么" |
| **P4 评审包** | 截图（1024/1440 × 亮/暗）、状态链接表、说明文档对齐 | 别人拿一条链接就能复现任意状态；文档里每个元素都能被指出来 |

顺序的理由：P0 决定"要不要认真看"，P1 决定"看不看得懂"，P2 决定"能不能自己走"，P3 只在被追问时用，P4 是交付物本身。

## 3 · 四条演示路径（原型真正的交付物）

这四条不是文档，是**能在页面上走出来的动作**。写在这儿是为了让每一处 UI 改动都有归属：改动不属于任何一条路径，就不做。

| 视角 | 90 秒路径 | 要让人说出的话 |
|---|---|---|
| **概览** | 打开 → 读到"七个月前那篇论文和十月那个小工具问的是同一件事" → 点 ✕ 之一 → 右栏看到两边的原文与依据 | "这两件事确实是连着的，我自己没注意到" |
| **时间轴** | 展开"答辩前那五天" → 30 条里 25 条没有产出 → 点其中一条 → 右栏写"什么都没产出" | "原来那五天是这样过的" |
| **探索** | 从 `mat-19` 走进去 → 两条边，一条是"矛盾" → 走过去看另一头 | "这两个判断不能同时为真" |
| **理解** | 打开 `ins-13`（高置信、且错）→ 展开"反驳它 2" → 点进一条原始活动 | "系统很确定，但它错了，而且它自己把反证摆在这" |

第三、四条是这套设计能不能站住的关键：**如果评审只在第一、二条上有反应，说明"发现"这件事还不成立，后面两条是在自娱自乐。**

---

## 4 · 现在做哪一件

**P0 里的两件：三层材质 + 图形尺寸。**

不做版心（780 / 页边），不做编排（地形图停住、分段），不做暗色。

理由：材质和尺寸决定"第一眼是不是被设计过"，而版心与编排是读到第二屏才影响的东西 —— 它们放在 P1 之后。
一次只推一个阶段，否则改完说不清是哪一处起了作用。

---

## 5 · 完成定义（原型到此为止）

五条全中，原型就算做完，**不再往下打磨**：

1. 四条演示路径都能一次走完，中途不需要人解释。
2. 12 条交互全部有行为，页面上没有一个死按钮。
3. 五个边界各有一张截图，且每张都能说出它想说明什么。
4. 4 组截图（1024 / 1440 × 亮 / 暗）都看过，没有一处塌。
5. 说明文档与页面一致：文档里写的每个限制，在页面上都能找到对应的样子。

第 5 条最容易被跳过，也最容易在评审时被问倒。

## 6 · 风险（都在原型范围内）

| 风险 | 表现 | 对策 |
|---|---|---|
| **改个不停** | 每一轮都"更好看"，但四条路径一条也没走顺 | 按 §2 走，一个阶段一次截图验收 |
| **只在亮色下验证** | 暗色一塌，评审一切换就露馅 | P3 必须出暗色截图 |
| **图形加过头** | 为了"有图"而画图，图上信息比文字少 | 每个图形都要能回答"它比文字多告诉了什么" |
| **演示路径靠讲解** | 需要你在旁边说"先点这里"，说明它本身不成立 | 找没看过的人试走一次 |
