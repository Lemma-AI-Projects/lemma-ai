## 1 · 理论：只留真正解释现象的

不是"每个概念配一个理论"。下面每一条都标了**在本研究里用不用**。

### 1.1 用的

| 理论 | 核心主张 | 能解释 | **不能**解释 | 用在哪 |
|---|---|---|---|---|
| **社会认同理论** Tajfel & Turner (1979) | 最小分组即产生内群偏袒；认同来自**比较**与**边界** | 为什么"对所有人说话"产生不了认同 | 公司怎么造出一个"群" | `03` §2 |
| **组织身份** Albert & Whetten (1985) | 身份 = 中心的、持久的、独特的 | 为什么身份主张必须**前后一致** | 外部受众是否接受这个主张 | `02` C6 |
| **品牌社区** Muniz & O'Guinn (2001) | 三标志：同类意识、仪式传统、道德责任 | 提供了可数的判据 | 规模化的条件 | `03` §3.2 |
| **实践共同体** Lave & Wenger (1991); Wenger (1998) | 三条件：互相参与、共同事业、共享行话；新人从边缘进入 | 成员**如何变成**成员（这是"身份"的动力学） | 超过几百人后如何治理 | `03` §3 |
| **制度合法性** Meyer & Rowan (1977); Suchman (1995) | 合法性是资源，来自外部受众的"理所当然" | 为什么新类别必须先被**第三方**承认 | 谁有资格授予合法性 | `03` §4.3 |
| **制度同构** DiMaggio & Powell (1983) | 组织会向同领域强者趋同（强制/模仿/规范） | **为什么"差异化"会被组织自身的生存压力磨平** | 何时趋同是策略而非失败 | `05` H0 |
| **类别社会学** Zuckerman (1999); Phillips & Zuckerman (2001); Durand & Paolella (2013); Buhr, Funk & Owen-Smith (2021) | 不合法折扣；**地位分层**（高地位可跨类，中地位须守规，低地位无入场资格）；偏离与评价是曲线关系 | 为什么"类别重构"对一家两个月的公司是**负资产** | 软件行业是否与证券/电影/餐饮样本一致 | `03` §4.3、`05` H3 |
| **网络效应** Katz & Shapiro (1985) | 直接/间接网络效应产生赢家通吃 | 平台为什么能逃逸 | **为什么私密使用的产品没有直接网络效应** | `05` H1 |
| **路径依赖 / 报酬递增** David (1985); Arthur (1989) | 小事件锁定大结构；锁定靠**转换成本** | 早期选择为何不可逆 | 在转换成本近零的市场里是否还成立 | `05` |
| **生成性** Zittrain (2006) | 系统允许未被预设的贡献 ⇒ 创新来自外部 | 开源生态为何难以被超越 | 生成性同时意味着**不可控** | `04` §2.3 |
| **组织双元性** Tushman & O'Reilly (1996) | 探索与利用需要**两套组织** | 为什么"两个人同时做产品和做制度"结构性不可能 | 多小的组织可以兼做 | `05`、`07` |
| **文化资本 / 社会资本** Bourdieu (1984); Coleman (1988); Putnam (2000) | 品味是区分工具；关系网络本身是资本 | "品味型市场"为何小而高价值 | 品味如何变成收入 | `05` H2 |

### 1.2 明确不用的（以及为什么）

| 框架 | 不用它的理由 |
|---|---|
| **破坏性创新** Christensen | 解释的是"在位者为何被低端颠覆"，与"公司如何长出产品之外的价值"无关。硬套会把它写成"我们是颠覆者"，那是叙事 |
| **蓝海战略** Kim & Mauborgne | 价值曲线工具实用，但"开创无人竞争的市场"在实证上缺乏可复现的因果证据；且它天然鼓励类别跳跃 —— 与本研究的 `03` §4.3 结论相反 |
| **Category Kings / Play Bigger** | 实务手册，不是研究。"品类王拿 76% 市值"这类数字没有可核的方法说明。它的价值是**词汇**，不是**证据** |
| **7 Powers** Helmer | 实务框架，但**可用作清单**：规模经济、网络经济、反向定位、转换成本、品牌、独占资源、流程能力。本文只在 `07` 用它做一次清点，并注明它是实务框架、非同行评议 |
| **飞轮 / 增长飞轮** | 描述性隐喻，不含可证伪的因果。写进战略文档只会让人以为已经想清楚了 |

### 2.1 Etsy —— 反例：身份资产怎么被一次"放宽定义"销毁

| 七问 | 回答 |
|---|---|
| **1 最初的核心价值** | 2005 年创立，只卖**亲手做的东西**。价值 = 可信的出处（provenance） |
| **2 产品之外的价值何时出现** | 2013 年前后：**"handmade" 成了一个身份**。卖家自称 Etsy seller，买家以"支持手艺人"自我认同 |
| **3 哪些机制互相强化** | 身份（我是手艺人）→ 供给（独特商品）→ 买家认同（我支持真实的人）→ 溢价 → 更多手艺人 |
| **4 什么能被复制** |  marketplace 本身极易复制。**不能复制的是"这批人在这里"** |
| **5 结构性转折** | **2013-10**：政策允许"manufacturing partners"，把 handmade 的定义从"亲手做"改为"你创作"（NPR / Consumerist 当时的报道；Etsy CEO 的公开解释是"handmade 指的是 authorship 与 transparency"） |
| **6 后果** | 2015 上市，规模增长；2022-04 卖家罢工（导火索是交易费 5%→6.5%，但请愿书里第二个诉求就是"清理非手工商品"）；2024-07 再改成四档标签（made by / designed by / handpicked by / sourced by）—— **不是把墙重新砌起来，是给已经进来的工厂贴标签** |
| **7 不能迁移到 Lemma 的** | Etsy 的身份建立在**可验证的物质出处**上；学习没有等价物（没人能验证"这是我学会的"）。⇒ Lemma 的身份必须建在**过程**上，而过程天然不可验证 |

**【推断】机制提炼（这是本案例唯一值得带走的东西）：**
> 身份资产的折旧不是因为"公司变坏"，而是因为**边界判据变得不可验证**。
> 一旦"你是不是我们的人"无法判定，身份就退化成标签，标签退化成文案。

⇒ 对 Lemma 的直接含义：如果身份是"真的学会了的人"，那么**必须有办法判定"真的学会了"**。而现在判定只有一种证据：答对/答错（`VG:B2`），而这恰恰是"可以全答对而完全不理解"的那种证据。

### 2.2 Makerbot —— 反例：把公地关上，公地带着人走了

| 七问 | 回答 |
|---|---|
| **1 核心价值** | 2009 年起的开源桌面 3D 打印机 + Thingiverse（2008）模型共享社区 |
| **2 产品外价值** | 社区贡献的模型、改装方案、固件 —— **公司的研发有相当部分在外部** |
| **3 强化机制** | 开源硬件 → 玩家改 → 改法回流 → 更好卖 → 更多人改 |
| **4 可复制** | 硬件可复制；**社区的知识存量不可复制** |
| **5 转折** | 2012 年 Replicator 2 转为闭源（以"专利与竞争"为由），社区强烈反弹 |
| **6 后果** | 2013 年被 Stratasys 收购；品牌逐步淡出消费市场。**开源社区转向前述的其它项目** |
| **7 不可迁移** | 硬件受专利与制造约束，软件不受。**Lemma 没有"必须闭源"的技术理由** |

**【推断】** 这条案例的价值不在"开源好"，而在于：**关上公地的那一刻，你损失的不是代码，是贡献者。** 而贡献者一旦走了，不会回来 —— 因为他们的下一次贡献会去别的地方。

### 2.3 Blender —— 正面：公共物如何变成制度

| 七问 | 回答 |
|---|---|
| **1 核心价值** | 一款建模软件（原公司 NaN 2002 年破产） |
| **2 产品外价值** | 破产后**社区出钱把代码买下来**，以 GPL 放出，成立 Blender Foundation |
| **3 强化机制** | GPL（谁都能改）→ 公司赞助开发基金（NVIDIA/AMD/Epic/Meta 等）→ 基金会中立（不站队）→ 工作室产出教学与影片 → 行业采用（影视、游戏） |
| **4 可复制** | 软件功能可复制。**不可复制的是"中立性"**：一家公司无法宣称自己中立 |
| **5 转折** | 2002 年开源；此后**每年一次的 Blender Conference** 与公开路线图，把"谁决定什么"变成了公开程序 |
| **6 后果** | 成为影视/游戏管线里的常规工具；商业公司反过来为它出钱。**价值归属不在任何一家公司** |
| **7 不可迁移** | Blender 的资产是**代码 + 中立治理**。Lemma 的产品是**私有的学习过程**，天然不可公共化 |

**【推断】** 关键机制：**基金会的作用不是"开放"，是把"谁说了算"制度化。** 这解释了为什么 `03` §4.4 提到的"自己造评价者"是可能路径之一 —— 但代价是**公司让出控制权**。

### 2.4 Unity —— 反例：信任资产可以在两周内清零

| 七问 | 回答 |
|---|---|
| **1 核心价值** | 跨平台游戏引擎，降低发行成本 |
| **2 产品外价值** | 2010 年代形成的开发者生态：Asset Store、教程、插件、社区问答 |
| **3 强化机制** | 引擎免费/低价 → 开发者多 → 资产与教程多 → 新人更容易上手 → 更多开发者 |
| **4 可复制** | 引擎可复制（Unreal/Godot 都在）；**生态不可复制** |
| **5 转折** | **2023-09-12** 宣布按安装量收取 Runtime Fee |
| **6 后果** | 开发者大规模抗议、部分下架与迁移；公司在数周内多次修改方案；CEO 于 2023-10 卸任。**信任没有恢复** |
| **7 不可迁移** | Unity 的资产高度集中在**单一决策的后果**上；学习产品的信任分散在每一次交互里 |

**【推断】这是全系列最重要的一条经济学事实：**
> **关系型资产的建设是线性的，摧毁是瞬时的。**
> 这个不对称意味着：任何以"信任/认同/社区"为核心资产的战略，其**风险敞口是凸的** —— 上行是缓慢的复利，下行是一次性归零。
> ⇒ 融资叙事里"文化护城河"这种说法，必须配一句"它的最大回撤是 100%"。

### 2.5 Bell Labs —— 半反例：制度性逃逸成功，然后被所有权结构杀死

| 七问 | 回答 |
|---|---|
| **1 核心价值** | 1925 年成立，为贝尔系统提供电话网络所需的技术 |
| **2 产品外价值** | 晶体管（1947）、信息论（1948）、Unix（1969）、C 语言等 —— **产出远超任何单一产品** |
| **3 强化机制** | 垄断利润（长话费）→ 无需短期回报 → 长期研究 → 反哺网络 → 更强的垄断。**跨学科不是设计出来的，是被"不用急着变现"允许的** |
| **4 可复制** | 实验室可复制，人才可挖。**不可复制的是"不需要证明短期价值"的资金结构** |
| **5 转折** | **1984** AT&T 拆分（垄断利润被切开）→ 1996 朗讯分拆 → 2008 阿尔卡特朗讯退出基础研究 |
| **6 后果** | 制度消失，**产出留在世界上**（晶体管不属于贝尔 Labs） |
| **7 不可迁移** | Lemma 没有垄断利润；也没有一个愿意为 20 年后的东西付钱的母公司 |

**【推断】这条案例最扎人的地方：**
> Bell Labs 证明了 Type B 可以成立，但它成立的条件是**一个不需要短期回报的资金结构**。
> 一家 VC 支持的初创公司，**结构上就是不满足这个条件的**。
> ⇒ 所以 Lemma 若要走 Type B，必须找到**除了 VC 之外的第二种资金结构**（基金会？收入自养？机构合作？）—— 否则它在第一天就与自己想要的形态在资金上冲突。

这一条在 `07` 会作为最硬的一条结论出现。

### 2.6 Y Combinator —— 正面：把一个"身份"做成制度

| 七问 | 回答 |
|---|---|
| **1 核心价值** | 2005 年起：小额投资 + 三个月 + Demo Day |
| **2 产品外价值** | "YC 校友网络"。公司真正的产品逐渐变成**成员资格**本身 |
| **3 强化机制** | 批次（同期=同班）→ 校友互助 → 校友当 LP/导师/投资人 → 新人更想进 → 筛选更严 → 标签更值钱 |
| **4 可复制** | 加速器模式完全可复制（全球有几百个）。**不可复制的是"YC 公司"这个标签在第三方那里的效力** |
| **5 转折** | 【推断】转折点是**外部投资人开始按"是不是 YC"来筛项目**的那一刻 —— 标签的使用权从 YC 手里转移到了第三方 |
| **6 后果** | 成为创业领域的一个**分类词**。这个词的合法性不由 YC 单独授予 |
| **7 不可迁移** | YC 的身份有**明确的代价**（让出股份、三个月、公开路演），Lemma 没有任何等价物 |

**【推断】这是"类别重构成功"最干净的样本，注意它满足三个条件：**
1. 有**代价**（不是免费的）
2. 有**批次**（时间上的分组，天然产生"我们这届"）
3. **第三方**（投资人）先开始用这个词做筛选

⇒ 对照 `03` §4.2 的三个检验：YC 三条全过。而 Lemma 目前三条全否。

### 2.7 Cursor —— 待检验假设：增长极快，但约束一条没少

【事实】（公开信息，来源标注在文末）
- 2022 成立。种子轮 2023-10（OpenAI Startup Fund 领投）。
- 2025-06：Series C，$900M，投后估值 $9.9B，ARR 超 $500M。
- 2025-11：Series D，$2.3B，投后估值 $29.3B，年化收入超 $1B，团队约 300 人。
- 2026 年初：据报道在谈约 $5B、估值 $50–60B 的新一轮。
- 2026-04：据报道 xAI 获得**年内以 $60B 收购 Cursor 的权利**（或支付 $10B 购买合作成果）。

| 七问 | 回答 |
|---|---|
| **1 核心价值** | 一个把 AI 深度嵌进编辑器的开发环境（VS Code 分支） |
| **2 产品外价值** | **弱。** 没有可识别的用户共同体治理、没有第三方采纳的类别词、没有公开的实践标准。品牌很强，但品牌是第 2 级（`03` §2.1） |
| **3 强化机制** | 产品体验 → 开发者日常依赖 → 口碑 → 更多开发者 → 更多交互数据 → 体验更好。**这是一个产品飞轮，不是制度飞轮** |
| **4 可复制** | 编辑器可复制（分支 VS Code）；模型可购买。**难复制的是产品工艺与迭代速度** |
| **5 转折** | 【推断】没有出现"产品之外的价值开始独立存在"的结构性转折。增长曲线一直在，**约束一直没少** |
| **6 后果** | 商业上极成功。但供给维度（前沿模型）从未逃逸；到 2026 年，这个约束以**所有权条款**的形式显形 |
| **7 不可迁移** | 开发者的身份天然外显（GitHub 上的绿格子、开源贡献），学习者没有等价物 |

**【推断】对创始人那个未验证判断的回答：**
> 「Cursor 可能没有完成多维逃逸」——**在"约束"这个定义下，这个判断成立**，但要给它一个准确的形式：
> **Cursor 逃逸了"需求"维度（用户离不开）和"组织"维度（品牌/招聘），没有逃逸"供给"维度。而供给维度是最短的那块板。**
> ⇒ 它验证的不是"增长没用"，而是 `03` §5.5 那条：**最弱的一维决定生死**。

⚠️ 同时必须指出反方向的可能：Cursor 自研 Composer 模型、并有 $1B+ 年化收入，**也可能正在把供给维度补上**。本机无法核实其自研模型在训练与推理上的自给程度。**这是本研究最大的未核实项。**

### 2.8 Figma —— 正面：社区面与产品面是同一个面

| 七问 | 回答 |
|---|---|
| **1 核心价值** | 2016 年上线：浏览器里多人同时编辑同一个设计文件 |
| **2 产品外价值** | 社区文件、插件、以及 **Config** 这类年度集会。关键结构：**它把"使用"和"展示"做在同一张画布上** |
| **3 强化机制** | 多人协作（社交原语）→ 作品天然公开可见 → 他人可复用/remix → 插件生态 → 更多团队采用 |
| **4 可复制** | 协作编辑器可复制。**不可复制的是"作品已经在里面"** |
| **5 转折** | 【推断】转折点不是功能，是**公开可复用的作品**开始成为设计师之间的通用语（发一个链接就能看懂） |
| **6 后果** | 2022 年 Adobe 宣布以约 $200 亿收购，2023-12 因监管反对终止；2025-08 独立上市 |
| **7 不可迁移** | **设计作品天生可公开，学习过程天生私密。** Figma 的社区不需要额外动作，Lemma 的社区需要用户主动暴露"我不会什么" |

**【推断】**这是全系列最重要的一条结构差别：
> Figma 的社区不是"运营出来的"，是**产品的工作面本身就是公共面**。
> 教育产品的工作面是私密的。所以 Lemma 不能照搬 Figma —— 它必须**先造一个可以公开的东西**（作品？掌握度？时间？），而那个东西现在不存在。

## 3 · 横向比较：把"约束"数出来

这是本系列唯一一次量化，量化的是**可数的东西**（约束条数），不是钱。

| | 供给 | 需求 | 评价 | 组织 | 结果 |
|---|---|---|---|---|---|
| **Figma** | 中（自研渲染引擎，不依赖外部模型） | **强**（团队协作=迁移成本） | 中（仍是"设计工具"，但 Config 已成行业仪式） | 强 | 独立、上市 |
| **YC** | 不适用 | 弱（不锁定） | **强**（"YC 公司"是第三方在用的词） | **强** | 制度成立 |
| **Blender** | **强**（GPL，谁都能维护） | 中 | **强**（文件格式即标准） | 强（基金会中立） | 制度成立，价值不归公司 |
| **Bell Labs** | **强**（垄断利润供养） | 不适用 | 强 | 强 | **供给一断，全归零** |
| **Etsy** | 弱 | 中 | 强→**自毁** | 中 | 身份资产折旧 |
| **Makerbot** | 弱 | 弱 | 中→**自毁** | 弱 | 边缘化 |
| **Unity** | 中 | **强**（项目沉没成本） | 强 | 强→**一周崩** | 信任归零 |
| **Cursor** | **弱** | **强** | 弱 | 中 | 增长极快，约束未减 |

**从这张表能读出三件事（全部为推断）：**

1. **"评价"维度最容易自毁，也最难重建。** 三家公司（Etsy / Makerbot / Unity）都栽在这里，且都是**自己动手**。
2. **"供给"是唯一不能靠时间解决的维度。** 它要么靠钱（自研）、要么靠结构（垄断/基金会），没有第三条路。
3. **同时逃逸四维的公司，一家都没有。** 最接近的是 Figma（三维较强、评价维只算中）。

⇒ 如果这条成立，那么"多维逃逸"作为战略目标可能**本身就是一个不可达的标准**。这个可能性必须交给 `05` 的 H0 处理，而不是被忽略。

## 4 · 案例的共同盲区（必须说明）

1. **样本偏向幸存者与知名公司。** 我挑的是"能说明机制"的，不是随机抽样。**没有一家失败的、默默无闻的公司被选进来**，因为查不到可靠的一手材料。
2. **软件与教育不同。** 除 YC 外，所有案例的用户都在**同一个可见的场域**里（代码库、设计文件、marketplace、引擎项目）。学习没有这样的公共场域 —— 这是 Lemma 面临的最大结构性差别，也是本系列所有"可迁移"判断都要打折的原因。
3. **时间尺度不同。** Etsy 用了 9 年到罢工，Unity 用了 13 年到崩塌，YC 用了约 10 年才成为分类词。**Lemma 成立两个月。** 任何"几年后"的判断在这里都不构成建议。
4. **我无法核实企业内部数据。** 所有"机制"解释都是从外部可见事实反推的，**存在其它解释**（例如 Etsy 的衰落也可能主要是广告与算法，而非身份）。本文给出的因果都标了 `【推断】`。
