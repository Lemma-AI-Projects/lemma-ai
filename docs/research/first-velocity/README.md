## 三条纪律

1. **不造数字。** 全系列没有用户规模、收入、市场份额、增长率。出现的数字都是已公开的事件（融资、法规、年份）。
2. **观察 / 推断 / 假设 三分。** 逐条标。`【事实】` 可回原文核；`【推断】` 是我的推理；`【假设】` 未验证。
3. **负面同权。** 反例先写，且案例表里 4/8 是反例或半反例。
