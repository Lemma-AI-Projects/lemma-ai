# 05 · 候选理论模型

> 分支 `practice-system` · 2026-10-27 · 状态：**未定**（五个模型并存，不选冠军）· 上游：`03`、`04`

> 每个模型必须有：机制 · 支持证据 · **反对证据** · 判别性观察 · kill condition · 对 Lemma 的资源要求。
> 没有 kill condition 的，是愿望，不是模型。
> **本节刻意不给出"推荐哪一个"。** 选择权在创始人，这里只负责让选项可被证伪。

---

## 0 · 先处理一个前置问题：A/B 二分法还站得住吗

**站不住。** 理由三条：

1. **案例里没有纯 A 或纯 B。** Figma 是产品驱动但长出了社区；Etsy 是社区驱动但退化回 marketplace；Blender 是纯 B 但**价值不归任何公司**（`04` §2.3）。二分法把这三家都归错类。
2. **A/B 混了三个互相独立的轴。**
   - **价值存在哪**：功能 / 累积数据 / 关系 / 制度
   - **谁在评价你**：市场分析师与类别图式 / 一群实践者 / 第三方机构
   - **复制者要付什么**：采购周期 / 时间 / 关系 / 政治
3. **同一个轴上的位置会随时间移动，而且可以往回走。** Etsy 移动过两次（一次往前，一次往后）。

### 0.1 替换成三维坐标（本系列后续都用它）

```
轴 1  价值载体：  功能 → 数据 → 关系 → 制度
轴 2  评价者：    用户 → 同行 → 第三方机构 → 无评价者（新类别）
轴 3  复制成本：  可采购 → 需时间 → 需关系 → 需政治许可
```

【推断】Type B 其实是**"轴 3 上移到后两格"** 的另一种说法。这个改写的好处是：它让"我们是不是 Type B"变成一个**可观察的问题**（复制者要付什么），而不是一个**身份问题**。

⇒ 下面五个模型都是"怎么把轴 3 往后推"的不同答案。

---

## H0 · 空假设：Type B 不产生可防御性，只产生期权与叙事

**主张**：文化、社区、身份这些东西**是真的**，但它们**不是护城河**。它们产生的是：更好的人才、更低的获客成本、更高的容错、以及在融资时的**期权价值**（万一成了）。真正的可防御性仍然来自"在一个被验证的小市场里做得比所有人好"。

**机制**：制度同构（DiMaggio & Powell 1983）—— 只要公司要融资、要招人、要和机构合作，它就会被拉回本领域的标准形态。文化是**约束条件下的装饰**，不是驱动力。

**支持证据**
- `Assess:937/942`：「产品在早期几乎没有护城河」「不能防复制，只能靠先开始」。
- `04` 横向表：**同时逃逸四维的公司，一家都没有。**
- `04` §2.5：Bell Labs 的 Type B 依赖一个不要求短期回报的资金结构 —— VC 结构不提供。
- `04` §2.4：关系型资产的最大回撤是 100%。
- `03` §3.3：学习类社区的先例都由"身份跃迁"驱动，不由"爱学习"驱动。

**反对证据**
- YC 确实把"身份"做成了制度（`04` §2.6），且它是 VC 结构内的。
- Figma 的社区面与产品面是同一个面，两者互相强化（`04` §3 表）。
- 如果 H0 全对，那 Lemma 的差异化（拒绝帮忙）也救不了它 —— 但 H0 无法解释为什么这个差异化在**教学上**成立。

**判别性观察**：找到一家公司，其产品被明确追平之后，**仍然**靠文化/社区维持了收入或人才优势。
- 找到 ⇒ H0 削弱。
- 找不到 ⇒ H0 暂时胜出（并意味着 `07` 应该写"不要在融资里讲文化护城河"）。

**kill condition**：出现一家"产品落后但用户不走、且能招到人"的公司。

**对 Lemma 的要求**：无。这是**不作为**的选项，成本最低，也最诚实。

## H1 · 时间资产模型：护城河 = 买不到的行数

**主张**：唯一不可采购的输入是**时间 × 用户 × 关系深度**。具体到 Lemma：**"同一个人的同一个状态下，哪种干预真的让他动了"** 这类记录（`method-system-research.md:298` 原话）。

**机制**：先发者累积的**效应知识**（不是用户数据）构成一个公共品：新用户进来时，系统已经知道"对这类状态，先做 X 比先做 Y 好"。竞争者可以抄功能，但抄不到**已经跑过多少轮**。

**支持证据**
- `Assess:937` 自己承认：「唯一不能复制的是已经积累了多久的行」。
- `04` §2.5：Bell Labs 的产出不可复制，因为它需要**不用急着变现的二十年**。
- Katz & Shapiro (1985)：间接网络效应来自"更多人用 ⇒ 产品更好"，与"用户之间是否互相看见"无关 —— 这一点对私密使用的学习产品**是成立的**。

**反对证据（最硬的一条）**
- **学习产品没有直接网络效应**：A 的学习不会让 B 学得更好，除非效应知识真的跨人迁移。而这条正是 `02` A1 的隐性假设，**从未被验证**。
- 若效应高度个体化（每个人的最优路径几乎不重合），那么累积的是**个体记忆**，不是**跨用户资产** ⇒ 竞争者不需要抄你的行，它只要每个用户重新练一遍，成本相同。**H1 当场失效。**
- `VG:B1`：空间记忆现在只有"最近 20 条原文"，不是知识。**今天连"行"都还没开始积累。**

**判别性观察**：同一个方法在**不同用户**身上是否表现出可重复的效应差异。
- 可重复 ⇒ H1 成立的前提有了。
- 不可重复（主要是个体噪声）⇒ H1 死。

**kill condition**：跑了 50 个以上用户之后，"方法 × 状态"的效应无法跨用户泛化（即每个用户的最优方法不可预测）。

**对 Lemma 的要求**：① 跨用户的效应表（现在没有）② `VG:A1` 那个三连学习实验必须先跑通，否则连"一轮"都定义不了 ③ 把 `COMPLETION` / `SWITCH` 真正接上（`VG:A3/A5` 现在零调用方）。

## H2 · 拒绝模型：护城河 = "敢少帮忙"，认同来自被拒绝

**主张**：Lemma 唯一**今天就存在**的差异点是"它会把带帮助的成功排除在掌握之外"。这件事同时是：教学主张、产品原则、**身份来源**（`03` §2.4）。它构成**反向定位**（counter-positioning）：竞品**不敢**抄，因为抄了就等于告诉用户"你之前那些都不算"。

**机制**：
```
拒绝帮忙 → 用户必须自己动 → 产生"这是我做出来的" → 可公开的自我叙事 → 认同
                                    ↓
                          竞品不敢跟随（会得罪现有用户）
```

**支持证据**
- `backend/ai/knowledge/state.py:295-307` 的 Admission 三值已落地（见 `03` §2.4）。
- `method-system-design.md:103`：「敢少帮忙、并且能证明少帮忙是对的」。
- `mala-design.md:99`：主语必须放在用户身上。
- 反向定位在 7 Powers 里是被单独列出的一种力量（实务框架，`04` §1.2）。
- `03` §2.3：身份来自"拒绝做什么"，而不是"做了什么"。

**反对证据（最硬的一条）**
- **用户想要答案。** 所有 AI 产品的使用数据都指向"更快拿到结果"。一个告诉用户"你刚才那次不算"的产品，初期留存会**显著更差**。
- 认同需要**公开**，学习是**私事**（`03` §2.5）。
- 反向定位只在**竞品有存量用户包袱**时有效；如果竞品是新产品（如各家新出的学习 Agent），它没有包袱，抄得起。

**判别性观察**：把"这次带帮助"显式告诉用户之后，**次周留存**是升还是降。
- 升 ⇒ H2 有商业基础。
- 降 ⇒ H2 是道德优势，不是商业优势（这时应把它当**筛选器**用，而不是增长手段）。

**kill condition**：连续观察到"被指出没真会"的用户，其留存与付费**系统性低于**对照组，且没有出现小群的超额投入。

**对 Lemma 的要求**：① 一次真实的行为观察（`VG:A6` 说 prompt 写了但**一次都没看过回复**）② 一个"公开什么"的选择（作品？掌握度？时间？）—— 现在一个都没有。

## H3 · 类别顺序模型：先拿合法性，再谈重构

**主张**：**类别重构不是起点，是奖励。** 低地位主体跨类别会被折价（Phillips & Zuckerman 2001）。正确顺序是：在一个**已有评价体系**的类别里做出可验证的成绩 → 借成绩跨到相邻类别 → 反复几次之后，第三方开始用你的词。

**机制**：
```
可验证成绩（"这些人真的学会了"）
   → 借用已有评价者（大学/雇主/考试机构）的背书
   → 在相邻类别获得比较资格
   → 第三方开始复用你的术语
   → 类别词成立
```
注意：**每一步都需要一个 Lemma 之外的机构点头。**

**支持证据**
- YC：先有公司成功，才有"YC 公司"这个词被第三方使用（`04` §2.6）。
- Blender：先有可用的文件格式，才被写进别人的管线（`04` §2.3）。
- Zuckerman (1999) / Phillips & Zuckerman (2001)：地位分层。
- Buhr et al. (2021)：有成绩记录后，偏离类别的折价会**变平** —— 这是"先成绩后偏离"的直接理论支持。

**反对证据**
- `Pitch Desk.md:29` 明确拒绝应试体系：「不屑于为愚蠢的规则体系培养愚蠢的庸才」。**借用考试机构的背书与这条立场直接冲突。**
- 一旦进了已有类别（AI Tutor），就会被拿去和 ChatGPT 比价格 —— 而这正是创始人最想避免的（`Y Lemma.md:7`）。
- 有些类别重构确实从零开始（OpenAI 早期不是"AI 公司"）。**反例存在，只是很少。**

**判别性观察**：有没有一个**不领 Lemma 钱**的机构，愿意把"Learn Space / 掌握度 / 拒绝帮忙"写进它自己的流程。
- 有 ⇒ H3 路径打开。
- 没有 ⇒ 类别重构只能停在文案层（`03` §4.2 三检验全否）。

**kill condition**：24 个月内没有任何第三方机构采用 Lemma 的任一术语/口径。

**对 Lemma 的要求**：**这是最贵的一条** —— 需要一个"愿意背书的机构"（学校/公司/认证体系），而 Lemma 现在连一个都还没有。同时它要求做出**成绩记录**，而 `VG:A1` 说这件事从没发生过。

## H4 · 制度模型：从公司变成基础设施（代价是让出所有权）

**主张**：真正的逃逸只有一种形式：**你的东西被写进别人的流程**。达到这点的路径是造一个**不属于公司的公共物**（标准 / 开放数据 / 认证 / 基金会）。

**机制**（Blender 模式）：
```
私有产品 → 抽出可公共化的部分 → 用中立治理托管 → 行业采用 → 反向为它出钱
```
关键：**中立性不可由一家公司宣称**，必须交给一个结构（基金会/联盟/学术机构）。

**支持证据**
- Blender：破产后靠社区买下代码 + 基金会，才获得"中立"这个不可复制的属性（`04` §2.3）。
- Bell Labs：产出之所以跨领域，是因为它**不属于任何产品线**（`04` §2.5）。
- `03` §1.2：影响力必须有载体，且载体必须能离开公司独立存在。

**反对证据**
- **Lemma 的产品是私有的学习过程**，天然不可公共化。抽不出"公共物"。
- 让出所有权与 VC 结构冲突（投资人买的是**独占**的未来现金流）。
- 两个人没有余力做治理（`04` Tushman & O'Reilly：双元需要两套组织）。
- Blender 的结局是**价值不归公司** —— 这不是融资故事，是公益故事。

**判别性观察**：Lemma 能不能抽出**一件**不属于它的东西（一个公开的评测口径？一份开放的学习数据集？一个开源的教学方法规范？）。
- 能抽出，且有人用 ⇒ H4 有起点。
- 抽不出 ⇒ H4 不适用。

**kill condition**：无法在不损害商业利益的前提下，产出任何可公共化的资产。

**对 Lemma 的要求**：**最高**。且与融资目标结构性冲突，必须在 `07` 里明确写给创始人。

## 1 · 五个模型的关系（不是选择题）

| | H0 空假设 | H1 时间资产 | H2 拒绝 | H3 类别顺序 | H4 制度 |
|---|---|---|---|---|---|
| 时间尺度 | 立即 | 18–36 月 | 立即 | 24 月+ | 3 年+ |
| 现金成本 | 0 | 低 | 低 | 高（销售/合作） | 中（治理） |
| **要交出的东西** | 无 | 无 | 无 | 部分定义权 | **所有权** |
| 今天有几分基础 | — | 1/10（行还没开始积） | **6/10**（机制已在代码里） | 1/10 | 0/10 |
| 能否融资讲 | ❌ | ✅（"时间不可压缩"） | ⚠️（"我们在筛人"） | ✅（"我们在造类别"） | ❌ |

【推断】三条判断，供创始人反驳：

1. **H2 是唯一今天就有实物基础的模型**，但它的商业证据最弱。它更像一个**筛选器**而不是增长引擎。
2. **H1 是唯一能被写成"可防御"的模型**，但它有一个未验证的前提（效应跨人迁移），而这个前提**用 50 个用户就能测**。
3. **H3 与 H4 都需要"外部机构"，而 Lemma 现在没有任何一个**。在拿到第一个之前，这两个模型不能进入任何对外叙事 —— 否则就是 `Assess:937` 说的那句话：拿机制去融资。

### 1.1 如果只能选一个先做

【推断】先做**能测 H1 前提的那件事**，因为它同时是 H1 的前提、H3 的前提（要有成绩记录）、和 `VG:A1` 的缺口。

> **一句话：在讨论 Type B 之前，先让三个人在一个空间里连续学三次，并把证据落进表。**
> 这不是产品建议，是**研究前提** —— 没有这一行数据，H1/H3 都不可测，H2 无法观察，H0 无法排除。

## 2 · 本文档自己的 kill condition

如果出现下面任何一条，**本节的五个模型应当被整体重写**：

1. 创始人明确表示"Type B 只是融资叙事，不是公司形态" ⇒ H0 升格为结论，其余四个作废。
2. 出现一个案例：产品被追平、无第三方背书、无公共物，公司仍靠文化持续创造价值 ⇒ 五个模型的分类失效。
3. Lemma 拿到第一个机构合作方 ⇒ H3 从"未定"变成"进行中"，需要新的判别器。
4. 真实用户数据表明"被指出没真会"的用户留存**更高** ⇒ H2 从"可疑"变成"有据"，模型优先级需重排。
