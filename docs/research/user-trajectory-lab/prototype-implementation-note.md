## 0.7 · v5：配色并回产品

用户指出 v3–v4 的暖纸 + 赭「和 Lemma AI 的其他部分不一致」——成立。v3 借的是启示页的
「纸与墨」，那是**只属于启示页的另一套语言**；搬到别的页面，第一眼就是两个产品。

| 项 | v4（纸与墨） | v5（产品 zinc） |
|---|---|---|
| 桌面 | `--ut-desk #f4f1ea`（暖灰） | `bg-zinc-100 dark:bg-zinc-950`（同 `AppLayout` 外壳） |
| 主区 | `--ut-sheet #fffefb`（暖白） | `bg-zinc-50 dark:bg-zinc-900`（同内容页） |
| 浮层 | `--ut-panel #fff` | `bg-white dark:bg-zinc-900`（同 popover） |
| 文字 | 墨 `#1b1a17` / 暖灰 | `text-zinc-950/500/400` + 各自 `dark:` |
| 细线 | 发丝 `#e7e2d7`（暖） | `border-zinc-200 dark:border-zinc-800`（同产品 132 处用法） |
| 结构强调（选中、当前标签、编号、计数、在线线段） | 赭 `#8a5a2b` | `zinc-900`（暗 `zinc-50`）—— 选中态同 `SidebarItem` 的思路：深灰，不用彩色 |
| **信号色**（反驳 · 被收窄 · 候选刚浮出来 · 「你改过」） | 赭 | **amber-700/400**（暗 amber-400）—— 产品里 amber 本来就是「要注意」（REVIEW 徽章、警告图标） |
| CSS | `--ut-*` 三个变量 + 九个 token | **全部删除**，`index.css` 恢复原样；`--insight-*` 不动（启示页还在用） |

规则一句话：**结构一律 zinc，彩色只允许 amber 当信号**。全页现在只有两种颜色。

顺手修掉的真 bug：`?theme=dark` 把 `.dark` 挂在了**带颜色类的同一个元素**上，而
`@custom-variant dark` 是 `.dark *` —— 元素自己的 `dark:bg` 永远不生效，暗色下顶栏还是亮条。
改成外层包一层无样式 div。批量换类另有两个机械坑（`hover:` 前缀丢失、`text-ink` 吃掉
`text-inkmuted` 的前缀），都靠全量 grep + 截图抓出来。

## 2 · 页面结构

```
┌ 陈知远 · 2026.01 — 11 · 合成数据 │ 概览  时间轴  探索  理解 │        已放进暂存 · 暂存 2 ┐
├───────────────────────────────────────────────────────────────┬──────────────────┤
│ 主区（四个视角，共用 720px 单列版心）                            │ 右栏（选中才有）  │
│  概览    两条发现 + 一条折叠 + 一年的地形                         │  ← 类型 暂存 ×    │
│  时间轴  顶部线索条 + 按月分组的父子事件                          │  标题（衬线）     │
│  探索    搜索框 + 现在在 + 连到 N 处                              │  一行元信息       │

```

**没有选中时右栏不存在**，主区自动撑满。这是"细节按需出现"的最直接实现：不多一个空面板。

## 3 · 交互模型：一个选中、一块面板、一个按需面板

原来有四套并行的"看细节"入口（右栏、右键菜单、抽屉、弹窗）。现在只有一套：

| 动作 | 落点 | 反馈 |
|---|---|---|
| 选中任何东西 | 右栏；路径推进一步 | 行左侧 2px 实线 + 极浅底 |
| 沿连接走 | 连接块里的对象名 / 「走过去 →」 | 右栏左上出现 `←`，按一次退一步（最多 8 步） |
| 暂存 | 右栏顶部「暂存」 | 头部即时回执「已放进暂存」，1.6 秒消失；再点一次移走 |
| 并排 | 暂存面板底部（≥2 个对象才出现） | 主区域换成对比表，返回即退出 |
| 回应解释 | 右栏底部三个文字动作 | 列表行立即改状态（你改过 / 你否掉的） |
| 处理候选 | 右栏（只有"浮出来"的才有动作） | 状态变「已了结」，一句回执 |
| Esc | 关暂存 → 退对比 → 关右栏 | — |

**为什么去掉右键菜单**：菜单里 4 项和右栏完全重复，还把内容挡住；"存入集合"与"加一句话"点了做同一件事。
去掉之后没有功能损失，反而少一次"菜单打开→找项→点"。

## 4 · 四个视角各自只做一件事

| 视角 | 只回答 | 刻意**不**做的事 |
|---|---|---|
| 概览 | 有什么值得发现 | 不显示统计、不显示最近活动、不列全部线索详情 |
| 时间轴 | 事情怎么展开 | 不显示每条的依据条数（只留一个 1px 点表示"有/没有"）；不显示事件类型文字 |
| 探索 | 它和什么连着 | 不重复右栏的"它出现在哪几件事里"；不画图 |
| 理解 | 浮现出什么模式 | 不在列表里就能审批候选；不默认展开全部证据 |

**四条克制规则**（写进代码注释，也写进这里）

1. 一屏之内最多两个"大标题"（概览的两条发现，20px 衬线）。
2. 每条列表行只有一个信息层 + 一个 10px 的元信息行。
3. 说明性文字只在"不说会误判"时出现：`同框，不等于有关系` · `系统在攒的，不是待办` · `不评分，也不计连续天数`。其余全删。
4. 不新造交互：全页只有三种可点元素 —— 行、行内引用（虚线下划线）、文字动作。

- **图形一律 SVG**，不混字符：`marks.tsx` 是唯一出口，线宽 1.1–1.25，颜色 `currentColor` + `text-*` 类，暗色不用另画一份。
- **两处仍用字符**：`·` 分隔符（它是标点，不是图形）、以及没有任何图的纯文本行。

- **六档字号**：9.5（页眉小字）· 10（标签/元信息）· 12（正文）· 12.5–13（行标题）· 17（右栏标题，衬线）· 27（首页大标题，衬线）。

## 6 · 数据模型假设（与 v1 相同，只有第 7 条变化）

1. **五类不做成五个 tab**：对象 / 事件 / 证据 / 解释 / 候选在同一个空间里，四个视角是看法。
2. **父事件 = 一段过程**：两层，`parentId` 为空即顶层。`origin: system` 的标「系统并的」且可拆。
3. **证据与活动分离**：54 个事件只产 13 条证据，绝大多数事件 `evidenceIds: []`。右栏对空的那句只写"什么都没产出"。
4. **四态**：`observed` ● / `interpretation` ◐ / `hypothesis` ○ / `confirmed` ◆。`ev-18`（"我能读懂了"）是自述，不是证据。
5. **矛盾不裁决**：`ins-13` 高置信且与两条证据冲突，两条 `contradicts` 原样挂着，用户没看过。
6. **解释会过期**：`ins-12` 有 `effective_to` 与一段 `reinterpretation`，旧版本不删。
7. **候选也走同一个选中模型**（v2 新增）：`refOf` 认 `cand-*`，点进右栏才看到信号与三个动作。
   列表里它不要求你做任何事 —— 这是"候选不是待办"的界面实现。
8. **临时结构不动底层**：「提出为理解」产出的是 ○ 假设，作者是用户，标注"系统没有验证过"。
9. **v3 加了一条连接 `conn-05`（mat-19 ↔ foc-02）**。原因不是叙事需要，是原来四处连接八个端点、

## 7 · 已知限制

| 限制 | 后果 |
|---|---|
| 只有一份合成数据、一个虚构用户 | 测不了多用户 / 多 Space / 跨来源合并 |
| 没有后端与持久化 | 刷新即清空：暂存、对比、回应、候选处理都不落库 |
| **发现是手写的 3 条 + 4 条结构连接** | 不能证明"系统能持续产出发现"。仍是最大的未验证项，v2 没解决也没打算解决 |
| 探索里没有"关系图" | 只有 4 条连接时够用；真实数据若连成网，需要另想表示 |
| 无移动端 | 1024 可用；手机不可用 |
| 无键盘导航与完整 ARIA | 只有展开/关闭/返回有 `aria-label`；未做无障碍审计 |
| 暗色模式没看过 | 用的是语义 token，理论上跟随，但没截图验证 |

## 10 · 这版之后还能测什么

v1 的合成数据本来就是为"让弱的信息架构活不下来"准备的。这版把其中三样摆到了明面：

1. **未归类**：37 条活动没有线索、11/29 材料不挂课。v2 的探索只给"从这几处开始"，不假装有导航树。
2. **一条证据两个方向**：`ins-13` 的「反驳它 2」默认展开，支撑折叠 —— 任何"越确定显示得越重"的默认样式会在这里翻车。
3. **候选不是待办**：列表里只显示状态与条数，动作全在右栏 —— 想验证"不打扰"是否成立，看这里。

要验的是：**当用户看到一条和他有关的判断时，他会不会去点那两条反驳。**
