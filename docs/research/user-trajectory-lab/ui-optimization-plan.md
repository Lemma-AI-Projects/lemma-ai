## 一、先说一个被证伪的猜测

我原本以为"廉价感"来自中文衬线掉到了宋体。**用 CDP 查了真实渲染字体，不是。**

| 元素 | 计算值 | 实际用的字体 |
|---|---|---|
| 首页大标题 h2（27px） | `ui-serif, Georgia, Cambria, "Times New Roman", serif` | **Noto Serif SC**（27 个字形） |
| 正文 p（13px） | `Inter, ui-sans-serif, system-ui, …` | **Microsoft YaHei UI**（68 个字形） |

结论有两层：

1. **这台机器上字体没坏** —— 标题是正经的中文衬线。所以字不是"廉价"的主因，别把时间花在换字体上。
2. **但字是"没人管"的**：`src/index.css` 的 body 栈里没有一项含中文，`font-serif` 也没被覆盖，全靠操作系统默认映射。换一台没装 Noto Serif SC 的 Windows，标题就是宋体。这是**风险**，不是现状缺陷，5 行 CSS 就能堵上，不该排第一。

（这里吃了"先量再改"的教训第二次：上一轮时间轴"轴看不见"，我以为是颜色太浅，量完才知道是 `items-start` 让线高度塌成 20px。）

## 二、真正的三条病根

### 1. 没有材质：三层表面只差 3 个色阶

- `paper` #fbf9f4 / `plane` #fdfdfa / `panel` #fff —— 1024 截图里，右栏和页面**几乎同色**，只剩一条 `border-l` 在撑。
- 全页两处阴影，都在同一个方向，且都是 28–30px 扩散 / 2–3% 不透明度 —— 等于没有。
- 时间轴轴 `1px / --insight-leaf`、节点 `10px / 60% 墨`：要盯两秒才看见。
- hover `ink/2.5%` 和选中 `ochetint/70` 在浅底上差别极小，鼠标扫过去分不清"指着"和"选中"。

### 2. 图形太小，小到像噪点

| 图形 | 现在尺寸 | 在截图里读到的 |
|---|---|---|
| 时间轴节点 | 10px / 1.1 线宽 | 一排小点，形状分不出 |
| 发现标记 | 22px / 1.1 线宽 | 标点符号级别的装饰 |
| 证据比例条 | 46 × 4px | 像一条下划线 |
| 关系括号 | 高 66px | 像一条分隔线 |
| 四态记号 | 12px | 要看标签才知道是什么 |

图形该有的作用是"让人先看图再看字"，现在这五个都在**图的尺寸上做成了注释的尺寸**。

### 3. 空间和密度没有关系

- 版心固定 720px：1440 屏右边空 500px（像一份 Word 文档），1024 屏又刚好。
- 12px 正文 + 1.95 行高，同屏没有一个"实"的块：标题之后全是同一档灰度。
- 时间轴 40 行没有节奏差，每行"日期 + 标题"，读到第十行就失去焦点。
- 整页没有视觉锚：顶栏只有 4 个词 + 一个名字，第一眼不知道自己在哪一层。

## 三、P0：三组，做完就能拿去给人看

### P0-1 · 材质（先做这个）

| 项 | 改法 | 判据 |
|---|---|---|
| M1 | 三层重新定值：页面 `#f7f4ee`（比现在深一档）、板 `#fff`、浮层 `#fff` + 双层阴影（近 `0 1px 2px/6%`，远 `0 16px 40px/-24px/18%`） | 眯眼看截图，能一眼分出"纸 / 板 / 浮层"，不需要看边框 |
| M2 | 右栏从"列"变成"浮层"：主区右侧留 12px 纸，面板四边描边，进来 160ms 右移到位的 8px 位移 | 面板看起来是"放上去的"，不是"切出来的" |
| M3 | 顶栏：加 1px 内高光（`inset 0 -1px 0 rgba(255,255,255,.65)`）+ 底部 8px 的极浅暖影；内容滚到它下面时能看出前后 | 滚动内容经过顶栏下沿时，边界清楚但不靠加粗线 |
| M4 | 三档交互态拉**开**：hover `ink/4%`、选中 `ochetint/80` + 2px 赭线、当前视角 `ochre` 2px 下划线 | 鼠标快速扫过时，"指着"与"选中"两种状态同时存在也不混 |

### P0-2 · 图形的尺寸（不是形状）

| 项 | 现在 | 改成 |
|---|---|---|
| G1 时间轴节点 | 10px / 1.1 | **14px / 1.3**；形状从 6 种收到 **4 种**（学习=圆、创造=三角、反思=菱形、转向=右指向）＋里程碑=实心菱形 |
| G2 时间轴轴 | 1px `leaf` | **1.5px** `leaf`；每月方块 5 → 7px，与轴同色 |
| G3 首页发现标记 | 22px / 1.1 | **28px / 1.3**；`connection` 用赭色（唯一一处置色），其余墨色 |
| G4 证据比例条 | 46×4 | **64×6**，段间 1px `paper` 缝，**反驳段永远贴最右**（现在按顺序拼，读起来像进度条） |
| G5 关系括号 | 高 66 | **高 104**；节点 r 2.8 → 4；分支 ≥4 时收成 3 + "+N" |
| G6 四态记号 | 12px | **13px**；并在「理解」首次进入时给一行图例（4 个记号 + 一句话），之后不再出现 |

### P0-3 · 版心与密度

| 项 | 改法 | 判据 |
|---|---|---|
| D1 | 版心 720 → **780**；≥1280 时改成"页边 + 正文"两栏：左 96px 放编号与竖线（现在只有首页有），正文左对齐 | 1440 截图右边空白 ≤ 320px；四个视角左边缘在同一条线上 |
| D2 | 正文 12 → **13**；长段落行高 1.95 → **1.8**；所有数字 `tabular-nums` | 60 字说明每行 34–40 字 |
| D3 | 时间轴行高 34 → **40**；标题 12.5 → **13**；父事件标题 13 → **14** 且 `500` | 一屏 11–13 行，父子层级不用看字重也能分出来 |
| D4 | 首页首屏加**一个 27px 的引文块**（用户原话，`◆` 标记，占 3 行），放在第二条发现之后 | 首屏有"大—中—小"三级，不是两级 |
| D5 | 顶栏加一个视觉锚：左侧名字前加 18px 的赭色小方块（品牌位），四个视角的标签 12 → 12.5 并统一字距 | 第一眼知道这是"一个人的轨迹"，不是设置页 |

### P0-4 · 字体（5 行，顺手做，别当主线）

| 项 | 改法 | 判据 |
|---|---|---|
| F1 | 在 `@theme` 里定 `--font-sans`（含 `PingFang SC / Source Han Sans SC / Microsoft YaHei`）与 `--font-serif`（含 `Noto Serif SC / Songti SC`） | 换一台机器截图，标题不再可能落宋体 |
| F2 | 字重只留 400 / 500；标题 500 | 全页 `font-weight` 只有两个值 |
| F3 | 标题 tracking `-0.02em`；英文与数字在中文里前后各留 1/4 空格（`text-spacing-trim` 或手工 `\u2009`） | 标题里 "NeRF" 不贴中文 |

## 四、P1：信息与节奏（结构对了，改编排）

| 项 | 问题 | 改法 |
|---|---|---|
| I1 | 时间轴 40 行一个节奏 | 每 5 行插一条比 `hair` 更浅的分隔；每月第一行标题加 1px 上边距 |
| I2 | 地形图点完直接跳走，看不到自己选了哪条 | 点击**先停在该行**（选中态），再点"进时间轴"才跳；行 hover 整行浅底 |
| I3 | 地形图没有"现在" | 加 11-04 的竖虚线 + 顶部小字"今天" |
| I4 | 探索搜索没有"没有结果"的下一步 | 无结果时给三条"最近看过"，而不是一句"换个词" |
| I5 | 理解列表没有分组 | 按"有争议（有反驳）/ 平稳 / 没有证据"三段分开，段头一行小字 |
| I6 | 首页第三条发现被压成一行，读不到 | 改成"折页"：只露标题 + 一行 why，点开在原地展开（不跳走） |

## 五、P2：手感与可达（不影响第一眼，但不能没有）

| 项 | 改法 |
|---|---|
| E1 过渡 | 面板 160ms、hover 80ms、视角切换 120ms 淡入；只用 `transform` / `opacity` |
| E2 键盘 | ↑↓ 走列表、Enter 选中、Esc 关面板（已有）；每行加 `focus-visible` 2px 赭环 |
| E3 暗色 | 纸墨有 `.dark` 变量但**一次都没看过**：跑一遍，重点修 `--insight-hair`（深底上几乎消失）与 `--insight-leaf` |
| E4 空态 | 三处"没有"要各说各的：搜索无结果 / 筛选无事件 / 该类没有解释 |
| E5 长内容 | 右栏超长时底部动作吸底；首页滚动时"发现"小标题吸顶 |

## 六、明确不做

- **不做装饰性动效**：无视差、无弹簧、无骨架屏、无粒子。
- **不引图表库**：现有三张图手写 SVG 不到 200 行，够用。
- **不改回卡片**：分组手段仍是留白 + 细线。
- **不动数据层**：预计这轮不需要新增记录。
- **不做手机版**：只保证 ≥1024。

## 七、验收（每阶段同一套）

| 检查 | 方法 |
|---|---|
| 类型 / 规范 / 构建 | `tsc -p tsconfig.app.json` · `eslint src/features/user-trajectory` · `vite build` |
| 交互 | `node …/tools/drive-prototype.mjs` + `drive-compare.mjs`（22 项） |
| 视觉 | 1024 / 1440 × 亮 / 暗 = 4 组截图，逐张看；**眯眼测试**：能否一眼分出纸 / 板 / 浮层三层 |
| 字体 | `CSS.getPlatformFontsForNode` 查真实字体（这次就是这么证伪的），而不是看 CSS 声明 |
| 尺寸 | 用 CDP 量节点/轴/条的盒子，不靠目测 |

**每个阶段结束必须能回答一句**：这一版比上一版，第一眼强在哪？答不出来就是白改。

## 八、顺序

| 阶段 | 内容 | 工作量 | 为什么在这 |
|---|---|---|---|
| 1 | P0-1 材质 + P0-4 字体 | 小 | 材质是"贵不贵"的唯一来源；字体 5 行，顺手 |
| 2 | P0-2 图形尺寸 | 小 | 只改数字，不动结构 |
| 3 | P0-3 版心与密度 | 中 | 改版心会连带所有页面的留白，放最后 |
| 4 | P1 编排 | 中 | 依赖 1–3 的尺寸 |
| 5 | P2 手感与可达 | 中 | 不影响第一眼 |

第 1 阶段做完就停下来看一次。如果那时已经"贵"了，第 3 阶段的版心可以只做一半。
