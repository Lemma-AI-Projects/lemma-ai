## 7 · 仍然没有的东西

| 缺什么 | 为什么还缺 | 对 UI 探索的影响 |
|---|---|---|
| **第二个用户** | 任务只要一个人 | 多用户、同龄参照、社区类界面测不了 |
| **一条活动产多条证据** | 仍然一对一（ev-19 挂了 2 条活动，但不是反过来） | "这次对话还支持了什么"的反查测不出来 |
| **同一证据被两个用户使用** | 没有第二个用户 | 无关 |
| **声音 / 视频材料** | 这个人不录 | 音频时间轴测不了 |
| **连续的测评序列** | 只有 4 次零散测验 | 任何"能力随时间上升"的曲线仍然是编的 |
| **时长 / 花费** | 没有任何投入时长记录 | "投入多少小时"类视图不成立 |
| **协作痕迹** | 他没有合作者 | 评论、共编类界面测不了 |
| **8 月空档的原因** | 数据里没有 | "为什么停了"只能显示"不知道" |
| **3 条以上 Focus 的活动** | 刻意没做 | 多列布局在 3 列以上会不会崩，测不出来 |
| **同一天里跨线索的密集冲突** | 密集期基本集中在 foc-07 | 横向布局在密集时段的抖动问题测不到 |

## 8 · 三个统计陷阱（本轮新增一条）

1. **"读完 12 件"不等于学到 12 件。** `mat-08` 读完零笔记零证据；`mat-23` 看 9 讲只留一页。
2. **活动数不等于进展。** 06-05 那天 8 条活动、0 条证据。任何热力色块都在撒谎。
3. **线索条数不等于线索重要性。** `foc-07` 33 条全靠截止日期堆出来的；`foc-02` 19 条摊在 9 个月里，
   但它才是这个人真正的走向。按活动数排会把任务排到第一位。
