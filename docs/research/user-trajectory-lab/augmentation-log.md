2. **foc-02 与 int-02 同时存在且都不包含对方**。int-02 是"我关心这件事"，foc-02 是"这十个月我沿这条问题走了多远"。

4. **foc-07 不是他选的**。它的来源是答辩日期，不是好奇心。全库唯一一条任务型线索。
