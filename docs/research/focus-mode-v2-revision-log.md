## 新增（7）

1. **五级行动类别** Observe/Prepare/Propose/Act/Interrupt + **成本不对称原则**
   （默认多备少动）——V1 交互模型只有 Propose 一种形态。
2. **Move 生命周期**（prepared→presented→engaged/dismissed/adopted/superseded/expired）
   ——Move 从一次性 UI 插入变为持续对象；用户直接操作 Agent 产物 = 非 Chat 回应通道。
3. **关系层**（最小：并置 + 引用边）——内容模型第三层；E9 要检验它落在块层还是画布层。
4. **E9 竞争性判别实验**——同任务三路线 mock；表现接近时按实现成本取舍（brief 要求）。
5. **`track(move)` 第五原语**——Agent 读取/更新建议命运；重复抑制与撤回恢复的前提。
6. **子目标边界时机假设** [DH]——打断成本最小的位置；从"何时介入不可计算"变为可检测事件。
7. **产物型/操作型 move 区分**——Method directive 声明目标能力，干预器据此判断是否在替代练习。
