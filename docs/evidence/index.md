## 这个子目录回答什么

证据层是 Learner State 的**依据层**。它不回答"用户是谁"（User Home）、不回答"空间发生过什么"（Space Memory）、
也不回答"现在该教什么"（Coordinator / Global Agent）。它只负责一件事：

> **把一次学习行为变成一条可判定、可追溯的记录，让"掌握状态"可以被算出来，而且算得有据可查。**

## 三条最容易搞混的边界（先记住）

1. **记忆 ≠ 证据**：记忆记"这个空间发生过什么"，证据记"据此判定他会不会"。记忆**不承载掌握度**。
2. **证据 ≠ 状态**：证据是发生过的事实（只增不改）；状态是从证据**算**出来的视图（不落库，可重算）。
3. **条数 ≠ 得分**：任何地方都不许把"证据条数"渲染成百分比、掌握度或置信度。

## 什么时候回来改这里

- 证据的作用域规则变了（`project_id` 不再是唯一 scope）
- 新增/删除证据字段（尤其**加了来源字段**）
- ①④⑥⑦⑧ 任意一条回流通道被接通
- 自由课程 / 题库 / 教学会话 任意一个接进了证据
- **核心里新增/删除公共面**（`admit` / `revise` 这类）—— 2026-09-26 就发生过一次，当时三份文档据此重写过

改动清单里每一项都会让 04 过期；04 是快照，**过期了就更新它，别在旁边再写一份**。
